## ✨ About QRify

**QRify** is a lightweight and user-friendly QR code generator that transforms your text, URLs, and other information into QR codes in seconds.

No complicated process. Just enter your content, generate your QR code, and you're ready to go.

## 🚀 Features

| Feature | Description |
|:---|:---|
| ⚡ Instant Generation | Generate QR codes quickly |
| 🔗 URL Support | Convert website links into QR codes |
| 📝 Text Support | Turn plain text into QR codes |
| 📥 Download | Save generated QR codes |
| 📱 Responsive | Works across different screen sizes |
| 🎨 Simple UI | Clean and easy-to-use interface |

**1. Clone the repository**

```bash

```

**2. Navigate to the project**

```bash

```

**3. Launch the application**

Open `index.html` in your preferred browser.
